# Gestor de Empleo

Dominio: API para administrar candidatos, empresas y ofertas laborales, facilitando la organización de oportunidades de empleo.

## Requisitos

- Node.js 20 o superior.
- Git.
- Postman para probar los endpoints.

## Cómo correrlo

1. Abrir una terminal en la carpeta del proyecto donde está `package.json`.

2. Instalar las dependencias:

   ```bash
   npm install
   ```

3. Iniciar el servidor:

   ```bash
   npm run dev
   ```

4. Abrir `http://localhost:3000/health`.

   Respuesta esperada: **200 OK**.

   ```json
   {
     "status": "ok"
   }
   ```
